# mem0 pack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the mem0 Nebari pack: a hardened mem0 v2.2.1 image behind a path allowlist, a Go token proxy and secret generator, a Helm chart with CloudNativePG, an admin-key grant and NetworkPolicies, and CI that proves the journeys on kind against a fake model.

**Architecture:** mem0's own server code runs unmodified inside our `mem0pack` entrypoint, which writes its config row, checks it at start, answers health and enforces the allowlist. A Go sidecar injects a Keycloak client-credentials token into mem0's model calls. The chart wires both, makes the admin key with a Job, grants named callers read access, and closes the network around mem0 and its database.

**Tech Stack:** Python 3.12, mem0ai 2.2.1, FastAPI/Starlette ASGI, SQLAlchemy, alembic, pytest, ruff; Go 1.25 stdlib; Helm 3, helm-unittest, kubeconform; CloudNativePG 1.30 (chart 0.29.0); kind with kindnet NetworkPolicy; GitHub Actions with `nebari-dev/.github` reusable workflows.

**Spec:** `docs/superpowers/specs/2026-11-25-mem0-pack-design.md`

- token-proxy listens on `127.0.0.1:8081`; health on `:8082`; refresh when remaining < min(30 s, 25% of lifetime).
- mem0 server port 8000; `/healthz` and `/readyz` unauthenticated; everything outside the allowlist 404; unscoped list/search 400.
- Go: table-driven tests; functions take interfaces and return concrete types; `log/slog`; errors `fmt.Errorf("verb noun: %w", err)`.
- No em dashes in any committed file. No AI attribution in commits or PRs.
- Each slice: one PR on `nebari-dev/mem0-pack`, stacked on the previous slice's branch. Do not merge.

## Review Focus

1. A caller sends `user_id` with a wildcard, an empty string, a list, or an `OR` filter to list or search: expect 400 before mem0 runs (Task 7 tests).
2. The token endpoint is slow or down when mem0 calls the model: expect a 502 from the proxy within the client timeout, never a forwarded request without a token, and recovery on the next call (Task 9 tests).
3. The `config_overrides` row is absent, stale, or malformed at server start: expect the server to exit non-zero with a message naming the mismatch (Task 4 tests).
4. The ensure-secret Job runs again after the Secret exists, or two Jobs race: expect no change to the existing value (Task 10 tests and journey 9).
5. A request path that differs from an allowed one only by a trailing slash, URL encoding, `..`, or case (`/memories/`, `/Memories`, `/memories/%2e%2e/reset`): expect 404 (Task 7 tests).
