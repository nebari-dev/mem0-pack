Interfaces this pack promises to others, or depends on from others. One row per contract. Changing a contract updates this file in the same PR.

Status is `new`, `changed`, `unchanged` or `unchanged (implicit)` (a contract nobody wrote down, pinned by a version or commit).

| Image names and values tag paths | new | mem0-pack | release.yaml `tag-paths` | n/a (new) | `quay.io/nebari/mem0-pack-server` and `quay.io/nebari/mem0-pack-tools` (also `ghcr.io/nebari-dev/mem0-pack/server` and `ghcr.io/nebari-dev/mem0-pack/tools`); values `image.tag`, `tools.image.tag`. | mem0 REST subset behind the allowlist | new | mem0-pack | Tapas gateway pods (and any caller the NetworkPolicy admits) | `image/tests/test_allowlist.py`, `image/tests/test_serve.py`, `image/smoke.sh` (allowlist section) | Promises: with the admin key (`X-API-Key`), only `POST /memories` (add), `GET /memories` (list), `GET /memories/{id}`, `DELETE /memories/{id}` and `POST /search`; `/healthz` and `/readyz` need no key. Scope rule: `user_id` is required on add, list and search; `agent_id` and `run_id` only narrow; scope values are literal non-empty strings, never `*`; `GET /memories` accepts only the query parameters `user_id`, `agent_id`, `run_id`, `top_k` and `show_expired`, each at most once (any other parameter or a repeat is a 400); the `{id}` in by-id paths must be a lowercase UUID (anything else is a 404); search takes no logical or operator filters; an add takes a top-level `user_id` and rejects a `filters` key. Errors: 404 with body `{"detail":"Not Found"}` for anything not allowlisted (`/auth/*`, `/configure`, `/reset`, and the rest); 401 without a valid key; 400 for an unscoped add, list or search; mem0's own 4xx/5xx otherwise. Caveat: `GET /memories/{id}` answers 200 with `null` for an id that does not exist, and mem0 does not check ownership on by-id calls (get, delete), so callers must verify the memory belongs to the person before acting on it. |
| Admin key Secret readable by named callers | new | mem0-pack | Tapas gateway ServiceAccounts listed in `callers` | `chart/tests/caller-grant_test.yaml`, `chart/tests/ensure-secret_test.yaml` | The Secret is `adminKey.secretName` (default `mem0-admin-key`), or `adminKey.existingSecret` when set, with key `api-key`. When `existingSecret` is empty a Job (`<fullname>-ensure-secret-<hash>`, create-only RBAC) makes it once with random bytes and never rewrites it. Role `<fullname>-admin-key-reader` allows only `get` on that one Secret (`resourceNames`) and is bound to each caller's ServiceAccount; it renders even when `existingSecret` is set. Anyone who can read the Secret can read every person's memories. |
